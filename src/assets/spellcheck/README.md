# Spell-check dictionaries

Hunspell dictionaries for the editor's spell checker (`src/lib/spellcheck.ts`),
copied from wooorm's `dictionary-*` npm packages. Each language keeps the
license it ships with:

| Language | Package | License |
| --- | --- | --- |
| English (US) | dictionary-en 4.0.0 | MIT and BSD (SCOWL), see LICENSE-en |
| Spanish | dictionary-es 4.0.0 | GPL-3.0 or LGPL-3.0 or MPL-1.1, see LICENSE-es |
| Italian | dictionary-it 2.0.0 | GPL-3.0, see LICENSE-it |
| French | dictionary-fr 3.0.0 | MPL-2.0, see LICENSE-fr |
| German | dictionary-de 3.0.0 | GPL-2.0 or GPL-3.0, see LICENSE-de |
