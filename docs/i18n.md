# Translations

Icarus speaks English, Spanish, Italian, French and German. English is the
source; every other language mirrors it.

## App

- Catalogs live in `src/lib/i18n/messages/<locale>/`, one file per namespace
  (`common`, `settings`, `app`, `privacy`, `editor`, `nav`, `stats`,
  `tracker`). `en/index.ts` defines the `Messages` shape; each other locale's
  `index.ts` ends in `satisfies Messages`, so a missing or extra key fails
  `pnpm check`.
- Read messages through `t` and fill them in with `fmt`:

  ```svelte
  <script lang="ts">
    import { fmt, t } from '../lib/i18n/index.svelte';
  </script>

  <h2>{t.settings.title}</h2>
  <p>{fmt(t.common.entries, { count: app.entries.length })}</p>
  ```

- `t` is reactive. Anything computed from it in a component's script must be
  `$derived` (or computed in the markup), and plain modules read it when
  called, never at import time, so the text follows a language change.
- Placeholders are `{name}`. Numbers passed to `fmt` get the language's digit
  grouping, so pass years and other identifiers as strings.
- Counted messages use `plural({ one, other })` and a `{count}` param. French,
  Italian and Spanish may add `many`.
- Write whole sentences. Never glue fragments together or interpolate a
  phrase whose grammar depends on the sentence around it (such as "on this
  device" vs "in this browser"): add one key per variant instead.
- Dates and numbers go through `dateFormat(options)` and `formatNumber(n)`
  from the same module (or the helpers in `src/lib/date.ts`), never
  `new Intl.*(undefined)` or `toLocaleString()`.
- Spell check has a Hunspell dictionary per language in
  `src/assets/spellcheck/` (see its README for sources and licenses).

## Public site

Pages are rendered per language at build time by `site/i18n/plugin.ts` from the
templates in `site/` and the catalogs in `site/i18n/<locale>.ts`. English is
served at `/`, the others under `/<locale>/`.

## Adding or changing copy

Change English first, then the same key in every other catalog. Keep
placeholders, HTML tags and plural categories intact when translating.
