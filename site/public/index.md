# Icarus

Icarus is a free, open-source diary app for keeping a private diary over many years. It is licensed under the GNU General Public License v3, and the source code is at https://github.com/tiny-mammal/icarus.

- Home page: https://icarus.4oli.com/
- Web app: https://icarus.4oli.com/app/
- Desktop app for Windows, macOS and Linux: https://icarus.4oli.com/download

## What it does

- Write diary entries in a Markdown editor, with titles, locations and several entries per day.
- Browse entries in a calendar and move between days, months and years instantly, even with decades of entries.
- Search all entries by title, location or text.
- Import an existing diary from any `.ics` file and export the diary as `.ics` at any time.
- Keep unsaved drafts while writing.

## Privacy

- **Password encryption.** The diary and its drafts can be locked with a password. They are encrypted on the device, and without the password or the recovery key no one can read them.
- **Local-first.** There is no account, no server that stores diaries, no sync service and no tracking. The desktop app saves the diary in a folder the user chooses. The web app stores it in the browser's own storage on that device.
- **Open format.** Entries are saved in the standard iCalendar (`.ics`) format, so a diary is never locked into Icarus.

## Good fit

Icarus suits people who want a long-term personal diary or journal that stays private, works offline, and keeps entries in an open file format. It is not a shared notebook, a team wiki or a cloud-synced notes service.

## Frequently asked questions

**Is Icarus free?** Yes. It is free and open source under the GNU GPL v3, with no accounts, ads or subscriptions.

**Where is my diary stored?** Only on your device: in a folder you choose on desktop, or in the browser's storage in the web app.

**What happens if I forget my password?** Use the recovery key saved when the password was set. Without the password or the recovery key, the diary cannot be opened.

**Can I bring my existing diary?** Yes. Import any `.ics` file and each entry appears on its day.
